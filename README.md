<h1>Marketplace</h1>

<p>
An online marketplace application that allows users to create accounts,
list products for sale, and purchase products online.
</p>

<h2>Backend Technology</h2>
<ul>
  <li>FastAPI</li>
  <li>Python</li>
</ul>

<h2>Frontend Technology</h2>
<ul>
  <li>JavaScript</li>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<h2>Features</h2>
<ul>
  <li>User authentication</li>
  <li>Create and manage listings</li>
  <li>Browse marketplace listings</li>
</ul>

<h2>Instructions to Run (Tested on Ubuntu)</h2>

<h3>1. Clone the repository</h3>

<pre>
git clone repo_url
cd marketplace
</pre>

<h3>2. Create and activate virtual environment</h3>

<pre>
python3 -m venv .venv
source .venv/bin/activate
</pre>

<h3>3. Install dependencies</h3>

<pre>
pip install -r requirements.txt
</pre>

<h3>4. Run the server</h3>

<pre>
./run.sh
</pre>

<h3>5. Open the application</h3>

<p>
Navigate to:
</p>

<pre>
http://127.0.0.1:8000/static/login.html
</pre>

<h2>Notes</h2>

<ul>
  <li>The database is initially empty.</li>
  <li>Create an account to start adding listings.</li>
</ul>
